## 現在の実装段階

- 第1弾マスター: 85枚
- 第1弾画像: E1-01〜E1-85（85枚）
- 2列カード一覧
- 所持率表示
- 所持数
- お気に入り
- カード詳細
- 検索: カードID / カード名
- 絞り込み: キャラクター / ブランド / タイプ / レアリティ / カテゴリ / 所持・未所持 / お気に入り
- 並び替え: ID / レアリティ / AP / カード名、昇順・降順
- 弾切替時: 検索語・絞り込みはリセット、並び順は維持

次段階: ＋登録（OCR・未登録カード登録）

## 今回の追加：カード登録

- ＋登録からカメラ画面へ
- iPhoneの背面カメラを優先
- カードID付近を撮影してOCR
- OCR結果を必ず確認してから登録
- OCR失敗時は再試行またはID手入力
- OCR用画像はIndexedDB等へ保存しない
- 公式マスターにIDがあれば所持数を+1
- 公式マスターにないIDは未登録カードとして作成し、編集画面へ
- 同じ未登録IDの再登録は所持数を+1
- OCRはTesseract.js CDNを使用（通信が必要）

## 今回の追加：カード詳細画面
- 表示順：画像 → ID → レアリティ → タイプ → ブランド → カテゴリ → カード名 → AP → 所持数

## 今回の追加：弾選択画面

- カード一覧ヘッダーの「第1弾」部分から弾選択へ
- `data/index.json` に登録されている弾を一覧表示
- 現在選択中の弾は `●`

- 既存のE1マスター・E1画像は変更なし

## 今回の追加：IndexedDB永続化

IndexedDB `AikatsuEncoreDB` v1 を実装しました。

- userCards
- customCards
- customImages
- cardOverrides
- outfits
- offlineSets
- settings

お気に入り・所持数は `userCards` に保存され、再描画や再起動後も取得できます。
テーマや最終表示弾などの設定は `settings` に保存できます。
マスター自体はIndexedDBへ保存せず、公式マスターとユーザーデータを分離します。

`idb-test.html` で基本的な保存・取得・個別overrideリセットを確認できます。
